# The Kauhale Method

A way to run a large, long project as a household of AI agents. The guide itself is [kauhale-method.md](kauhale-method.md).

## Versions

Each shared version is a git tag named by date (`2026-10-09`). `CHANGELOG.md` says what changed in each one and why. To get the exact file someone received:

```
git show 2026-10-09:kauhale-method.md > kauhale-method_2026-10-09.md
```

A kauhale records the version it follows in its KAUHALE.md, section 1 (for example, "Kauhale Method 2026-10-09").

## Editing

1. Edit `kauhale-method.md` in this folder (Cowork pointed at this folder, or any editor).
2. Commit with a message that says what changed and why, and add a line to `CHANGELOG.md`.
3. When you send a version to someone, update the version line at the top of the guide, tag the commit with today's date, and push the tag.
